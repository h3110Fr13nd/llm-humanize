# Experimental Progression & Decoding Research

This directory contains the structured, reproducible record of our research on **Inverted Nucleus Sampling (Post-Top-P Boundary Decoding)** and **Confidence-Gated Hybrid Routing** using `SmolLM-135M` and `SmolLM-135M-Instruct`.

---

## Directory Standard per Experiment

Every experiment folder follows an identical, self-contained structure:

```
experiments/<XX>_<slug>/
├── README.md              # Context, hypothesis, configuration matrix, and findings
├── data/                  # Source texts, entity ground truths, and evaluation prompts
├── scripts/               # Standalone, runnable python CLI reproduction script
├── notebooks/             # Fully self-contained, independently runnable Jupyter notebook
└── outputs/               # Generated CSV metric tables, decision traces, and plots
```
